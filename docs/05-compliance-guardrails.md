# Compliance guardrails

## Non-negotiable rules
- Playback must go through the official unmodified TIDAL Player module / SDK path
- Do not circumvent playback restrictions
- Include TIDAL branding and link back to TIDAL service where required
- Do not imply endorsement by TIDAL
- Do not build voice control features
- Do not build AI features that use TIDAL content
- Do not combine TIDAL content with other streaming services
- Do not target business/public-setting use
- Do not enable downloading or external redistribution of TIDAL content
- Do not scrape or store end-user data unnecessarily

## Product implication
This project should be framed as a personal desktop client experiment for private use, with the first milestone limited to catalog browsing and official-player preview playback.

## Review gate
Before every new milestone ask:
1. Is this explicitly supported by public docs?
2. Does this require extra scopes?
3. Does this collide with developer guidelines?
4. Does this need application review / higher quota?
