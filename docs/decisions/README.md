# Decision records

For decisions that constrain several phases or would be costly to reverse. Ordinary
implementation detail doesn't get one.

Name them `NNNN-short-title.md` with:

- **Status:** proposed, accepted (with date), superseded (by which), or rejected
- **Context**
- **Decision**
- **Alternatives considered**
- **Consequences**

Agents may propose records; the owner accepts them (usually when merging the phase that
proposed them). An accepted record can refine the roadmap but never silently overrides
the owner or the active phase's brief.
